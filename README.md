# mygoReaction
An API for searching screencap by a line in anime MyGo.

## System Requirements 
- Java (open-jdk 17)
- PostgreSQL

## Installation (local start-up)
1. clone this project
2. create PostgreSQL DB named 'postgres'
3. modify the applicaion.property for setting the file path of the asset folder and DB link
4. start up the spring boot application
